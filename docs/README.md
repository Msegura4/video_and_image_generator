## 📝 Structure d'un guide

Chaque guide suit cette structure :
- **Introduction** : Objectif du guide
- **Prérequis** : Ce qu'il faut avoir avant
- **Étapes détaillées** : Instructions pas à pas
- **Exemples** : Cas d'usage concrets
- **Résolution de problèmes** : Erreurs courantes
- **Ressources** : Liens vers autres docs
